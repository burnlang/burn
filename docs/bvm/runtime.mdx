# Values and the runtime library

## Type ids

Every module starts with twelve built-in types. The types it declares are numbered from 12 on.

| Id | Type | Id | Type |
| --- | --- | --- | --- |
| 0 | `error` | 6 | `string` |
| 1 | `void` | 7 | `any` |
| 2 | `null` | 8 | `[any]` |
| 3 | `int` | 9 | `map<string, any>` |
| 4 | `float` | 10 | `[string]` |
| 5 | `bool` | 11 | `[int]` |

Runtime functions that have to understand a value take its static type id as an extra argument. For example
`to_str` takes the value and its type, so `const 3; rt to_str` formats an int and `const 11; rt to_str` formats
an `[int]` array.

## Heap objects

Heap objects start with a 16-byte header: kind (1 byte), cycle collector color, flags, padding, type id (4 bytes),
size in bytes (4 bytes) and reference count (4 bytes). After the header:

| Kind | Layout |
| --- | --- |
| string | length at +16, UTF-8 bytes at +24 |
| array | length at +16, capacity at +24, pointer to the elements at +32 |
| record | field `i` at +16 + 8·i |
| box | the boxed value at +16, with the type id of the value in the header |
| map, future | opaque, used through runtime functions |

Values of type `any` are boxes (or the object itself when it is already on the heap). `rt box v tid` creates one
and `unbox` reads it. `rt is_type`, `rt cast` and `rt type_name` inspect it.

## Reference counting

Objects are reference counted. A new object has a count of 1, owned by whoever created it: the result of `rt`
functions, `newarr`, `new` and calls is owned by the code that receives it. `rt retain v` adds an owner and returns
`v`, `rt release v` removes one and frees the object when none is left, releasing what it holds. Both ignore `null`
and strings from the module's string pool, which are static.

Containers own their contents: `newarr` and `new` take ownership of the values they are built from, and `rt`
functions that store a value (`arr_push`, `arr_set`, `map_set`, `box`, ...) add their own owner, so the caller
still releases its copy. `index`, `getfield` and `unbox` read without adding an owner. Burn generates these
instructions itself; another language on bvm must do the same, or its objects are never freed.

Objects that only refer to each other are found by a cycle collector, which runs when enough memory has been
allocated (`BURN_GC_THRESHOLD`, 32 MB by default; `BURN_GC_STATS=1` prints a line each time) and never while spawned
threads are running. While threads run, counts are updated atomically.

## Runtime functions

`rt name` pops the function's arguments (the first argument is deepest on the stack) and pushes its result.
Functions without a meaningful result return 0, so pop it. `bvm runtime` prints every name with its argument
count. The most useful ones:

### Text and output

| Function | Arguments | Result |
| --- | --- | --- |
| `print`, `print_raw`, `print_err` | string | prints with a newline, without one, or to stderr |
| `to_str` | value, type id | the value formatted as text (arrays, maps and records included) |
| `str_concat` | a, b | a new string `a + b` |
| `str_eq`, `str_cmp` | a, b | 1 if equal / -1, 0 or 1 |
| `str_len` | s | length in characters |
| `str_index` | s, i, loc | the character at `i` as a string |
| `str_sub` | s, start, end | substring (character indexes) |
| `str_find`, `str_contains`, `str_starts`, `str_ends` | s, t | index or -1 / bool |
| `str_replace` | s, from, to | replaces every occurrence |
| `str_split` | s, sep | `[string]` |
| `str_trim`, `str_upper`, `str_lower`, `str_chars` | s | transformed string / `[string]` of characters |
| `str_repeat` | s, n | `s` repeated `n` times |
| `str_code`, `str_from_code` | s / n | code point of the first character / string from a code point |
| `char_class` | s, kind | 1 if every character is a letter (0), digit (1), letter or digit (2), whitespace (3) |
| `parse_int`, `parse_float` | s, loc | the parsed number; a runtime error if `s` isn't one |
| `is_int_str`, `is_float_str` | s | bool |
| `input` | prompt | a line from stdin |
| `read_stdin` | | all of stdin |

| `map_keys`, `map_values` | map, array type id | an array |
