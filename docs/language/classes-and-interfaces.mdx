# Classes and interfaces

## Classes

```burn
def class Counter {
    priv int value = 0
    string label

    fun init(label: string) {
        self.label = label
    }

    fun increment(): Counter {
        value += 1
        return self
    }

    fun get(): int {
        return value
    }

    static fun named(label: string): Counter {
        return Counter(label)
    }
}

var c = Counter.named("clicks")
c.increment().increment()
print(c.label, c.get())
```

- Fields are declared like variables, with optional defaults.
- Inside methods, fields can be used directly (`value`) or through `self` (`self.value`).
- `fun init(...)` is the constructor used by `ClassName(...)`. Without `init`, `ClassName(a, b)` fills the fields
  in order, and `ClassName { field: value }` sets fields by name.
- `static fun` belongs to the class and is called as `ClassName.name(...)`.
- `priv` fields and methods can only be used inside the class.
- A normal method can also be called as `ClassName.method(instance, ...)`.

## Interfaces

```burn
def interface Shape {
    fun area(): float
    fun name(): string
}

def class Rect: Shape {
    float w
    float h

    fun area(): float {
        return w * h
    }

    fun name(): string {
        return "rect"
    }
}

fun total(shapes: [Shape]): float {
    var sum = 0.0
    for s in shapes {
        sum += s.area()
    }
    return sum
}
```

A class lists the interfaces it implements after a colon. The compiler checks that every method exists with the
same signature. Interface calls are dispatched through a table indexed by the class, so they are as cheap as a
normal indirect call.
