# Burn

Burn is a general purpose programming language with a clean syntax, static types that you rarely have to write,
and smart casts that follow your `if` checks. The compiler and its tools are written in Burn and run on bvm, the Burn
virtual machine, which is written in Rust.

```burn
def interface Shape {
    fun area(): float
}

def struct Circle(radius: float) :: Shape {
    fun area(): float {
        return 3.14159 * radius * radius
    }
}

fun describe(value: any): string {
    if (value is Shape) {
        return "a shape with area ${value.area()}"
    }
    return "something else"
}

print(describe(new Circle(2)))
```

## Ways to run the same program

| Command | What happens | Typical use |
| --- | --- | --- |
| `burni app.bn` | compiled to a bvm module in memory and run right away, starts in milliseconds | development, scripts |
| `burnc app.bn` | compiled to a portable `.bvmc` bytecode file, run with `burn` or `bvm` | distributing without a build per platform |
| `burnc app.bn --target bar` | the program and its bytecode libraries in one runnable `.bar` archive | shipping applications that run everywhere bvm runs |
| `burnc app.bn --target js` | compiled to a JavaScript file that runs with Node.js | running where Node.js is already installed |

On bvm the program always uses the same runtime, so it behaves the same way everywhere; the JavaScript build
carries a runtime written in JavaScript that matches it.

The virtual machine, [bvm](./bvm/overview.mdx), is not tied to Burn: it has its own assembly language, bytecode
format, verifier and Rust API, and other languages can compile to it.
