# Getting started

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/burnlang/burnup/master/install.sh | sh
```

This installs the whole toolchain into `~/.burn/bin`: `burni` (interpreter), `burnc` (compiler), `burnfmt`
(formatter), `burn-lsp` (language server), `ash` (package manager) and `burn`, which combines them all. Building from source needs Rust
1.85 or newer, and native executables need a C toolchain (`cc`). See [installation](./tooling/installation.mdx)
for options and other platforms.

## Hello world

```burn
print("Hello, World!")
```

```sh
burni hello.bn
```

Top level statements run from top to bottom. If the file defines `fun main()`, it is called after the top level code.

## A slightly bigger program

```burn
def type Todo {
    string title
    bool done = false
}

fun summary(todos: [Todo]): string {
    var open = 0
    for t in todos {
        if (!t.done) {
            open += 1
        }
    }
    return "${open} of ${len(todos)} still open"
}

fun main() {
    var todos = [Todo { title: "write docs" }, Todo { title: "ship", done: true }]
    print(summary(todos))
}
```

## Build a native executable

```sh
burnc todo.bn              # produces ./todo
./todo
burnc todo.bn -o bin/todo --emit-asm todo.s
```

The executable is small (a few hundred kilobytes) and does not need Burn to be installed.

## Try things in the REPL

```text
$ burni
>>> var names = ["ada", "grace"]
>>> names.length
2
>>> fun shout(s: string): string {
...     return upper(s) + "!"
... }
>>> shout(names[1])
GRACE!
```

## Format your code

```sh
burnfmt -w todo.bn
```

## Start a project

Once a program grows past one file, make it a project. The name says where the code will live:

```sh
burn init github.com/you/todo
cd todo
burn run
ash install github.com/you/colors    # add a package
```

See [projects and packages](./tooling/packages.mdx).
